# ai-button
ai-button

**Пример утилиты «Умный ответ на отзыв»:**

1. Вставьте текст отзыва (или ссылку)
2. Выберите тон (вежливый / профессиональный / с извинениями)
3. Нажмите «Сгенерировать»

**Результат через 5 секунд:** готовый ответ, который поднимает карточку в поиске Яндекс Карт за счёт встроенных SEO-ключей.

## 🧩 Продуктовая матрица

### 🚀 Вертикаль «Быстрые деньги» (массовый рынок)

| Утилита | Задача | Время решения |
|---------|--------|----------------|
| **Автоответ на отзывы** | Генерация ответа для 2ГИС / Яндекс Карт + SEO | 10 сек |
| **HR-конструктор** | Продающий текст вакансии + 5 вопросов для собеседования | 15 сек |
| **Пост для соцсетей** | Текст и хештеги под Instagram / Telegram | 10 сек |
| **Переписка с клиентом** | Ответ на возражение «дорого» или «подумаю» | 5 сек |

### 💎 Вертикаль «Нишевые решения» (высокий чек)

| Утилита | Для кого | Глубина |
|---------|----------|---------|
| **ИИ-Мастер-Приемщик** | Автосервисы | Перевод технического отчёта на человеческий язык + калькуляция стоимости |
| **Медскрипты** | Клиники | Ответы на претензии с юр. комплаенсом и эмпатией |
| **Генератор меню (ОАЭ)** | Рестораны, кафе | Автоматический перевод и адаптация под арабскую культуру |
| **Анализ фото блюд** | Кафе, рестораны | Через vision-модель: «порция меньше заявленной — 70% отзывов» |

### 🌍 Международный вектор (ОАЭ, GCC)

- **Двуязычная контент-фабрика** — адаптация английских смыслов под менталитет и перевод на Khaleeji.
- **Экономия** — $1500–$3000 в месяц на агентствах.
- **Локализация** — правильные диалекты, а не машинный арабский.
